# Jolt

Permanent core mechanic at every tier. **Do not remove.** ([[project-vault-v2]] §7)

Purpose: get unstuck, regain traction, escape awkward spots, fix bad orientation. A useful physical impulse, likely upward.

Matters most for the Cube ([[subdivision-tiers]] Tier 1), which "relies heavily on Jolt". Primary focus of the Bounce Yard module ([[map-generation]]). Part of the first prototype ([[prototype-plan]]).

**Cannot be monetized:** a shorter Jolt cooldown is an explicitly banned paid feature ([[monetization-rules]]). Jolt visual effects are allowed as cosmetics.

**In Studio (28 Sept 2026):** built and server-limited, `JoltVelocity = 48`, `JoltCooldown = 2.5` s, both prototype values ([[studio-build]]).
